# FangcunAI Network Visiter

本仓库用于发布和说明 **FangcunAI 中期选举相关内容访问客户端**。

请运行./fangcun_webcom.exe --help 来获得很多信息

## 用途

- 连接 FangcunAI 官方服务，访问中期选举相关内容。
- 源码为真实，但是直接运行不能获得token，请不要尝试不通过程序完成认证，这违背用户使用手册
- 客户端仅提供访问入口；身份认证由 FangcunAI 官方认证流程完成。
- 本仓库不代办认证、不出售访问资格，也不会要求你在非官方页面提交密码、验证码或身份证件。

## 下载与运行

请从本仓库的 **Releases** 页面下载最新的 Windows `.exe` 文件并运行，以访问 FangcunAI 中期选举相关内容。

下载后建议先核对发布页提供的 SHA-256 校验值，再运行程序。请勿从网盘、聊天群或其他非官方来源下载同名文件。

## 身份认证与隐私

- 身份认证应由 FangcunAI 官方登录或授权页面处理。
- 不要向任何第三方转交账号密码、短信验证码、会话令牌或身份证件。
- 如果程序要求提供与访问无关的敏感信息，请停止运行并通过仓库 Issues 联系维护者。

## 安全说明

- 本仓库在完成独立安全审计前，不宣称客户端绝对安全。
- 任何公司或组织背书都必须由对应官方账号发布正式声明；本仓库不会伪造公司名义、认证资质或安全保证。
- Windows SmartScreen 或杀毒软件给出警告时，不要关闭安全防护来强行运行；


## 联系方式

请通过本仓库的 GitHub Issues 反馈问题。涉及敏感信息的漏洞，请使用 GitHub 的私密漏洞报告功能。
